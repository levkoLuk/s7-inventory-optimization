# Оптимизация Управления Запасами для S7 Airlines

## Описание Проекта
Данный проект направлен на оптимизацию процессов управления запасами для S7 Airlines, фокусируясь на пяти категориях компонентов. Цель — разработать комплексную модель оптимизации на основе анализа категорий товаров, выбора оптимальных стратегий и применения методов ИИ (в данном случае, аналитических моделей и сценарного анализа). Ключевым результатом является оптимизация процесса работы с запасами для сокращения издержек и повышения эффективности.

## Входные Данные
Для анализа использовались два CSV-файла:
1.  `final_consumtion_train.csv` (был пуст, поэтому использовались данные из `final_orders_train.csv`).
2.  `final_orders_train.csv`: Содержит исторические данные о заказах компонентов, включая `order_id`, `product_category`, `product_id`, `order_date`, `delivery_date`, `amount`, `qty`, `valid_delivered_qty`.

## Анализ Категорий Товаров (ABC/XYZ Анализ)
Был проведен анализ пяти категорий (`product_category` с id от 0 до 4) с использованием классических методов:
-   **ABC-анализ:** Категории классифицированы по их вкладу в общую стоимость закупок.
    -   **Класс A:** Категории 0 и 4 (высокая ценность).
    -   **Класс B:** Категория 2 (средняя ценность).
    -   **Класс C:** Категории 1 и 3 (низкая ценность).
-   **XYZ-анализ:** Категории классифицированы по стабильности спроса (коэффициенту вариации).
    -   **Класс X:** Категория 1 (стабильный спрос).
    -   **Класс Z:** Категории 0, 2, 3, 4 (нерегулярный/волатильный спрос).

### Ключевые Особенности Категорий:
-   **Категории A-Z (0, 4):** Высокая ценность, нерегулярный спрос, длительный срок поставки.
-   **Категория B-Z (2):** Средняя ценность, нерегулярный спрос, самый длительный срок поставки.
-   **Категория C-Z (3):** Низкая ценность, очень большие объемы, высокая волатильность, относительно короткий срок поставки (один продукт).
-   **Категория C-X (1):** Низкая ценность, очень малые объемы, _стабильный_ спрос, короткий срок поставки.

Более детальный анализ представлен в `analyze_categories.py`.

## Предложенные Стратегии Управления Запасами
Для каждой категории были предложены индивидуальные стратегии, учитывающие их ABC/XYZ классификацию, сроки поставки и специфику спроса:

-   **Категории 0 (A-Z) и 4 (A-Z):** Агрессивное управление с фокусом на глубокое прогнозирование (advanced analytics, ML), тесное сотрудничество с поставщиками для сокращения Lead Time, высокий уровень сервиса с минимальным страховым запасом, автоматизация заказов.
-   **Категория 2 (B-Z):** Фокус на сокращение сроков поставки и снижении рисков дефицита, повышенный страховой запас (из-за самого длительного Lead Time), прогнозирование на основе событий.
-   **Категория 3 (C-Z):** Эффективное управление объемными, но дешевыми компонентами: использование EOQ для определения размера заказа, минимизация затрат на заказ за счет консолидации, автоматизация, буферные запасы на основе исторических пиковых значений спроса.
-   **Категория 1 (C-X):** Упрощенное управление, фокус на доступности при минимальных затратах: модели канбан или "два бункера", минимальные страховые запасы, консолидация заказов.

## Оптимизационная Модель Закупок
Разработана модель на Python (`optimize_inventory.py`), которая рассчитывает:
-   `annual_demand_qty`: Годовой объем спроса.
-   `avg_unit_cost`: Средняя стоимость единицы.
-   `avg_lead_time_days`: Средний срок поставки.
-   `service_level`: Целевой уровень сервиса.
-   `mean_daily_demand`: Средний дневной спрос.
-   `std_daily_demand_used_for_ss`: Стандартное отклонение дневного спроса, используемое для расчета страхового запаса.
-   `safety_stock`: Рекомендованный страховой запас.
-   `order_quantity`: Рекомендованный размер заказа (EOQ или адаптированный для Z-класса).
-   `reorder_point`: Рекомендованная точка перезаказа.

Модель использует эвристические правила для Z-класса, чтобы адаптировать расчеты EOQ и страхового запаса.

## Экономический Эффект и Сценарный Анализ
Проведен расчет годового экономического эффекта (`evaluate_impact.py`) от внедрения предложенных стратегий по сравнению с гипотетической "текущей" ситуацией (без оптимизации).

**Общий годовой экономический эффект от внедрения: ~8.07 миллиарда рублей.**

### Анализ Рисков и Предложения по Митигации:
В `evaluate_impact.py` представлены детализированные риски для каждой категории и соответствующие мероприятия по их митигации.

### Сценарный Анализ:
Рассмотрены два сценария:
1.  **Увеличение срока поставки на 20%:** Показано, как это влияет на необходимый страховой запас и потенциальные дополнительные затраты на дефицит при сохранении текущего уровня SS.
2.  **Снижение спроса на 10%:** Оценена потенциальная экономия за счет снижения затрат на хранение и размещение заказов.

## Структура Проекта

## Как Запустить Проект
1.  Убедитесь, что у вас установлен Python (версии 3.8+).
2.  Установите необходимые библиотеки:
    ```bash
    pip install pandas numpy matplotlib seaborn scipy
    ```
3.  Разместите файл `final_orders_train.csv` в корневой директории проекта.
4.  Запустите скрипты последовательно:
    ```bash
    python analyze_categories.py
    python visualize_data.py
    python optimize_inventory.py
    python evaluate_impact.py
    ```
    (Примечание: `analyze_categories.py` и `optimize_inventory.py` вызываются из других скриптов, но их можно запустить и отдельно для просмотра промежуточных результатов.)
5.  Результаты анализа, оптимизации и графики будут сохранены в текущей директории.
